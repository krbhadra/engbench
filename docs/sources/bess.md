## Knowledge traps (a competent BESS engineer knows; a model without the knowledge sizes wrong)

1. Size for end of life, not beginning: usable energy must include SOH_EOL (80 % / 70 % / 60 % depending on the stated definition) and the SOC window; nameplate kWh is not deliverable kWh (#1 p.10, #2 p.4).
2. Minimum string voltage is set at EOL + low SOC + full discharge current (IR drop with grown resistance), and must stay above the PCS minimum DC voltage (880-1003 V for SCS UP; 1300 V for SC5000UD-MV-US), while the full-charge voltage must not exceed 1500 V. Nominal-voltage arithmetic (416 x 3.2 = 1331 V) passes; 416 x 2.5 V = 1040 V fails the Sungrow window (#3, #10, #21).
3. Fuses: DC voltage rating >= system max voltage at the circuit L/R (an AC or 300 V module fuse in a 1500 V rack is wrong); continuous loading factor (Littelfuse F_L 0.75, Mersen A'2, Eaton K_t) plus ambient derating, so the fuse rating is well above the load current; interrupting rating must cover the sum of all parallel racks' fault currents (#5, #7).
4. Contactor vs fuse: the contactor cannot interrupt short circuits; its maximum interrupting rating must overlap the fuse's minimum breaking capacity, and BMS overload protection is required with aR fuses (#13, #5).
5. Conductors: 125 % continuous factor, then ambient correction and bundling adjustment, then termination temperature limit; the OCPD may only be rounded up to the next standard size below 800 A (#6).
6. PCS AC power derates with site temperature (3800 -> 3230 kVA from 25 to 50 C) and with low AC voltage / low power factor; the DC-side current limit can bind before the AC rating (#3).
7. Transformer kVA = kW / PF, then altitude and ambient derating (0.940 at 3000 m; standard basis 30 C avg / 40 C max) (#9).
8. Cycle-life figures quoted at 80-100 % DOD are to an EOL that differs from the sizing EOL; the PNNL average-DOD correction and one-full-cycle-per-day warranty limit change the throughput budget (#1 pp.20-22).
9. AC-AC RTE at the POI (82.6 %) is not the cell DC-DC RTE (89.6 %); the charge energy the grid must supply is E_discharged / RTE_AC (#1 Table 4.4, #15).

## Unverified / caveats

- BLAST-Lite: LICENSE file read as BSD-3 (copyright Alliance for Energy Innovation, LLC) but README/PyPI summaries say Apache-2.0; confirm before reuse.
- SAM/ssc, REopt, QuESt, PyBaMM licenses (BSD-3) come from search summaries, not from fetched LICENSE files.

- IEEE C57.91 ambient derating (1.5 %/C above 30 C for self-cooled) appears only in vendor blogs; not verified against a primary carrier. Hammond's altitude table is verified.
- NEC 3 % / 5 % voltage-drop informational note: secondary web sources only; the Bussmann SPD voltage-drop section (pp.243-245) exists but was not read in detail.
- USABC "3 C cell-to-cell" limit is cited in secondary literature; the NREL documents read state the requirement qualitatively ("acceptable temperature difference") without the number. CATL EnerOne+ states 3 C for its own product; that sheet is marked "Internal" and hosted by a reseller.
- CATL EnerOne 1P416S voltage range 1164.8-1497.6 V comes from a search snippet of a user manual (Scribd), not from the sheet read here.
- Eaton battery-storage fuse guide CA135002EN: headings verified, body text not extractable; Littelfuse and Mersen cover the same method with numbers.
- Littelfuse and Bussmann SPD PDFs were read from web.archive.org captures because the live hosts returned 403 / timed out; content is the vendors' published documents.
- SAND2015-1002 was grepped for sizing terms; it does not contain a cell-to-PCS sizing procedure, only service ranges, PCS PF requirement and glossary.
